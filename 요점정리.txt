1. 파일 입출력 및 파일 시스템 (File I/O)
가장 기본이 되는 저수준 I/O와 파일 상태 확인 함수들입니다.
파일 열기/닫기: int open(const char *pathname, int flags, mode_t mode); / int close(int fd);
읽기/쓰기: ssize_t read(int fd, void *buf, size_t count); / ssize_t write(int fd, const void *buf, size_t count);
파일 오프셋 조작: off_t lseek(int fd, off_t offset, int whence);
파일 상태 확인: int stat(const char *pathname, struct stat *statbuf); / int fstat(int fd, struct stat *statbuf);
디스크 동기화: int fsync(int fd);
파일 디스크립터 복사: int dup(int oldfd); / int dup2(int oldfd, int newfd);
디렉토리 관리: DIR *opendir(const char *name); / struct dirent *readdir(DIR *dirp); / int closedir(DIR *dirp);

2. 프로세스 관리 (Process Management)
프로세스의 생성, 실행, 종료 및 동기화에 필수적인 함수들입니다.
프로세스 생성: pid_t fork(void);
프로세스 실행: int execve(const char *pathname, char *const argv[], char *const envp[]);
래퍼 함수(가장 많이 쓰임): int execlp(const char *file, const char *arg, ...); / int execvp(const char *file, char *const argv[]);
종료 및 기다리기: void _exit(int status); / pid_t wait(int *wstatus); / pid_t waitpid(pid_t pid, int *wstatus, int options);
ID 확인: pid_t getpid(void); / pid_t getppid(void);

3. 시그널 처리 (Signals)
비동기적인 이벤트를 제어할 때 사용합니다.
시그널 설정: sighandler_t signal(int signum, sighandler_t handler);
고급 시그널 설정: int sigaction(int signum, const struct sigaction *act, struct sigaction *oldact);
시그널 전송: int kill(pid_t pid, int sig); / int raise(int sig);
타이머/대기: unsigned int alarm(unsigned int seconds); / int pause(void);

4. 메모리 관리 및 mmap (Memory Management)
mmap을 포함한 주소 공간 관리 함수들입니다.
메모리 매핑: void *mmap(void *addr, size_t length, int prot, int flags, int fd, off_t offset);
매핑 해제: int munmap(void *addr, size_t length);
보호 권한 변경: int mprotect(void *addr, size_t len, int prot);
동기화: int msync(void *addr, size_t len, int flags);
힙 영역 조절: int brk(void *addr); / void *sbrk(intptr_t increment);

5. IPC (Inter-Process Communication)
프로세스 간 통신을 위한 대표적인 도구들입니다.
파이프(익명): int pipe(int pipefd[2]);
공유 메모리(POSIX): int shm_open(const char *name, int oflag, mode_t mode); / int shm_unlink(const char *name);
세마포어(POSIX): sem_t *sem_open(const char *name, int oflag, ...); / int sem_wait(sem_t *sem); / int sem_post(sem_t *sem);

6. 멀티스레드 (Pthreads)
병렬 처리를 위한 POSIX 스레드 함수들입니다. (컴파일 시 -lpthread 필요)
스레드 생성/종료: int pthread_create(pthread_t *thread, const pthread_attr_t *attr, void *(*start_routine) (void *), void *arg); / void pthread_exit(void *retval);
스레드 기다리기: int pthread_join(pthread_t thread, void **retval);
뮤텍스: int pthread_mutex_lock(pthread_mutex_t *mutex); / int pthread_mutex_unlock(pthread_mutex_t *mutex);

7. 네트워크 프로그래밍 (Sockets)
서버-클라이언트 구조의 핵심 함수들입니다.
소켓 생성: int socket(int domain, int type, int protocol);
서버측 설정: int bind(int sockfd, const struct sockaddr *addr, socklen_t addrlen); / int listen(int sockfd, int backlog); / int accept(int sockfd, struct sockaddr *addr, socklen_t *addrlen);
클라이언트 접속: int connect(int sockfd, const struct sockaddr *addr, socklen_t addrlen);
